A 120-character loading-screen tip for the two readers staring at the same progress bar: the tired developer and the coding agent working for them. It never says which of them took the shortcut, so both are implicated and both feel seen — and underneath the joke it is real debugging advice, that the bug is sitting in the stretch of code nobody found interesting enough to read. `main.py` writes the line to `$MAKEFUN_OUTPUT_DIR/entry.txt` (or `/output/entry.txt`), byte-identical on every run.

## Run it

```sh
python3 main.py
```
